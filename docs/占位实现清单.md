# 占位实现清单

更新时间：2026-07-15

本文集中记录当前只完成架构或方法签名、尚未实现业务功能的位置。代码和契约中的
`TODO(...)` 是就近执行说明，本文是跨模块检查入口。

## 当前已真实运行的内容

以下内容属于最小基础设施，不是身份、权限或知识库业务实现：

- 从环境变量读取 API 地址和 Gin 模式；
- 启动、关闭 HTTP 服务并设置超时；
- 注册 `/api/v1` 路由和 `GET /healthz`；
- 身份和知识库路由统一返回 `501 NOT_IMPLEMENTED`；
- 测试验证占位路由存在且不会返回伪成功结果。

当前不存在账号校验、Token、会话持久化、权限决策、数据库访问、文件解析、知识发布、
向量化、RAG 检索、供应商调用或演示成功数据。

## TODO 使用规则

- TODO 标识使用稳定、可搜索的 `TODO(scope-action)` 格式。
- 实现一个 TODO 时，必须同时交付领域行为、依赖边界、错误映射、测试和契约更新。
- 不得只删除 TODO 或把 `501` 改成成功状态码来宣称功能完成。
- 一个操作完成后只删除该操作对应的 TODO，不批量清除相邻未实现事项。
- 涉及权限、数据持久化、外部供应商或真实数据时，必须先有明确设计和安全边界。

## 身份与权限

| 占位能力 | 代码入口 | 完成前必须具备 |
| --- | --- | --- |
| 外部身份认证 | `identity.Authenticator.Authenticate` | 供应商适配器、超时、重放保护、敏感字段规则和失败测试 |
| 创建访问会话 | `identity.Service.StartAccessSession` | 成员关系解析、作用域、过期、幂等、审计和存储接口 |
| 读取访问上下文 | `identity.Service.GetAccessContext` | 过期/撤销处理、机构隔离和防资源存在性泄漏测试 |
| 权限判断 | `identity.Service.AuthorizeAction` | deny-by-default 权限矩阵、策略版本和全作用域测试 |
| 结束访问会话 | `identity.Service.EndAccessSession` | 幂等、乐观并发、审计和失败恢复 |
| 撤销成员关系 | `identity.Service.RevokeMembership` | 操作者授权、作用域、关联会话策略和越权测试 |
| 撤销访问会话 | `identity.Service.RevokeAccessSession` | 操作者授权、幂等、乐观并发和跨机构测试 |

HTTP 占位入口位于 `apps/api/internal/httpapi/identity/handler.go`，每个方法当前必须保持
`501`，直到对应领域能力完成。

## 完成占位的验证门禁

每次实现一个占位能力，至少需要：

1. 更新关联设计或 Issue 的范围与不做事项；
2. 增加领域单元测试和 HTTP Handler 测试；
3. 覆盖成功、非法输入、未授权、跨作用域、并发冲突和依赖失败；
4. 同步 OpenAPI 请求、成功响应和稳定错误码；
5. 运行 `make check`，外部基础设施另用 integration build tag 验证；
6. 确认没有密钥、真实群众数据、真实音频或供应商原始响应进入仓库。
